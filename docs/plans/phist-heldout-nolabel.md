# P-hist: candidate held-out evaluation without full transcription

Status: proposal, 2026-11-20. No evaluation, reference construction, scan download or OCR run was performed. No candidate is registered or cleared of conflicts. The released old-print model has **not been measured on a held-out set yet** by this proposal.

## What can be measured

Existing digital editions can cheaply locate passages on scans, but they are not necessarily exact transcriptions of the images. Their discrepancies include edition changes, skipped commentaries, spelling, marks and transcription errors. A score against unverified text confounds these with OCR errors. Under [decision 0012](../../planning/decisions/0012-real-page-scored-sets.md), silver references are development signals, not benchmark results; simply calling a silver set held out does not change that. Nor should protected test pages be exposed as development signals. A genuine real-scan benchmark needs human-adjudicated image-matched references or a new maintainer decision. The economical compromise is to adjudicate a **small, randomly sampled, fixed subset**, not fully transcribe all books. The official 22-book test remains separate and blocked until its own references are ready.

## Registration and alignment protocol

1. Lead checks every full work, edition, scan and text against the private reservation list and all existing training, validation, pretraining, glyph banks and model initialization, including alternate editions and near duplicates. A previously contaminated work is ineligible; do not try to repair it by holding out different pages. Reserve accepted whole works and their derivatives against **all future training** before any construction. Record source IDs, exact revisions, licences and hashes in a private manifest; do not expose protected pages to workers. If origin or rights cannot be established, reject the item.
2. Before test inspection, freeze eligibility, stratified random sampling, region scope, matching parameters and failure handling. Obtain a separate non-test development source for implementing alignment. Later an authorized evaluation custodian uses existing scan text or a frozen independent alignment recognizer, locates verse/section anchors, then performs monotonic fuzzy matching over local page windows; use confidence and margin against alternative matches, detect repeats, omissions and reordered pages. Preserve raw text, original Unicode, page ID and coordinates. An OCR-assisted aligner may select easy text: record all pages attempted, failures and rejection reasons; do not report scores conditional on easy matches alone. No evaluation OCR is authorized by this plan.
3. Use a blind random audit across books, script, quality and match-confidence bands, including failures; independent human comparison to the scan checks complete selected regions, page boundaries, order, omissions and punctuation, with adjudication. Use the image as the source of truth. To estimate review effort, start with three random pages per cleared edition and include all low-confidence pages in the proposed sample. Set the final audit size and acceptable residual reference error before scoring. Keep the random audit and low-confidence review counts distinct and stop if the reference check fails. For partial regions report coverage and exclusions explicitly; full-page metrics require complete page references and reading order. A small adjudicated subset can become gold after registration, while the remainder is unscored silver.
4. Freeze model, scorer, segmentation, normalization and all thresholds before the custodian scores once. Follow [decision 0017](../../planning/decisions/0017-domain-separated-evaluation.md): CER, WER, line exact rate and CER, page CER median/p90 and fixed-threshold shares, plus reading-order/layout cost where references support them; stratify square/Rashi/mixed and pointed/unpointed. Cluster intervals by source or edition and account for shared works and type settings across editions. Report sparse strata descriptively. Report denominators and coverage. No reported result is promised until a registered set and suitable references exist.

## Part B. Generated old-print held-out set

This is a **generated-data measurement**. Exact labels describe rendered text. The result supports a secondary synthetic diagnostic, while real scans supply the benchmark for historical print. Use the same caveat as HeOCR's generated-document gate. [Generator gate rules](https://github.com/HeOCR/hocrsyngen/blob/6632c6cfc7a33e93fe89ac9de8fc8bc181019a4f/docs/document_generator_design.md#L356-L371)

Use verified public-domain Hebrew prose and rabbinic passages from separate pinned transcriptions. Record the underlying work, transcription edition and licence. For Project Ben-Yehuda, require the item-level public-domain mark and historic edition provenance. [Ben-Yehuda reuse terms](https://benyehuda.org/page/about) Ensure source passages and near duplicates are disjoint from training and all real-test passages; use different works if that cannot be established. Reserve text, layout variants, seeds and **entire font families** before rendering. Cross square, Rashi and mixed commentary layouts with clean, mild and strong degradation. Within each populated cell, draw distinct source passages across sizes, column counts and abbreviation density. Keep logical RTL labels, line and region boxes, and reading order. Validate shaping, marks, fallback and missing glyphs on separate development inputs. Freeze independent train/dev/test seeds and text before rendering; generate gold from renderer input, not OCR.
