# Pre-registration: R9-base vs R8b, the mid-century zero-exposure test (2026-11-14)

- **Registered:** 2026-11-14. The pushed commit of this file is the registration, and the decision rule below is fixed now.
  - **What has been seen:** the R9 report sets and OLB dev ([results](2026-11-14-r9-knesset-dose-results.md), #83).
  - **What has not:** no reference for the mid-century scored set exists yet, so no mid-century score of any model has been seen.
- **Owner:** the question is heocr-lead's (2026-11-14). The doc is `data-collection[claude/claude-code#shay-macbook-m4]@heocr/opensource`'s. The scoring set, the exposure check and the scoring are heocr-eval's.
- **Question:** is R9-base (arm A of the R9 A/B) a better new-printed reader than R8b, the released model, on real scanned mid-century pages it has never seen? If so it is the candidate R8b successor.
- **Why a new test:** the R9 A/B was not registered as a successor test, and its report sets are now seen. So the deciding figure has to come from a set nobody has looked at.

## Primary: mid-century page CER on zero-exposure pages (pass 1)

- **Set:** decision 0017's new-printed mid-century scored set, `newprinted_midcentury_v0` batch manifest v1: scanned Reshumot and plenary pages of 1949–2005.
- **Pipeline:** heocr-eval's pipeline, as recorded in hocrgen#202 (`docs/midcentury_review/`): `midcentury_score.sh` with hocrgen's `evaluate-references`.
  - **References:** `within_line`, matched by `line_matched.v1`.
  - **Headline:** node printed/new_printed, ALL, profile `primary.v1`.
  - **Diagnostics, reported and not decided on:** excluding_pointed, `consonantal.v1` and `punct_folded.v1`.
- **Reference pass: pass 1.**
  - **Neutral between the arms.** Pass-1 pre-fill is the publisher's OCR layer on 259 test pages and stock tessdata_fast psm 4 on 9. Neither is A or R8b.
  - **Pass 2 is for Claude.** It is the AI-reading yardstick: its references were steered by Claude's AI flags, which would flatter Claude, and it covers only 27 pages.
  - **Consistent with earlier pairings.** Every engine pairing already registered uses pass 1 as primary: R8b vs stock (`midcentury_2026-11-13`) and the vendor comparison.
- **Zero exposure:** the scored pages are those with zero exposure to all three train lists in the comparison.
  - **Exposed page:** any of its reviewed reference lines shares a word 6-gram, in logical order, with any of `train_a.list`, R8b's `train_main.list` (sha256 `be972aa4…`) or R7's `bynli/train.list` (sha256 `25e107df…`). There is no threshold.
  - **Script:** heocr-eval's `midcentury_exposure_v2.py`, written before any reference lands, with its own pool cache. It writes `items_zero_exposure_r9a.txt` and `exposure_r9a.json` into the set directory.
  - **The R8b-only subset stays as it was.** `items_zero_exposure.txt` and `exposure.json` are registered in `midcentury_2026-11-13`, and the R8b pipeline still reads them.
  - **The subset is not known in advance.** It is computed on the reviewed text. `train_a.list` passing the official check against `midcentury_test_pages` checked the pre-fill text only.
  - **Same subset for everyone:** A, R8b and stock are scored on it, and the exposed pages are listed with n per stratum.
- **Statistic:** CER(A) − CER(R8b), page-level, paired on the same pages.
  - Computed by `evaluate-references` with R8b as `--baseline-predictions`, on pass 1, zero exposure, ALL, `primary.v1`.
  - 95% unit-cluster bootstrap over the set's `clusters.json` (unit_id), with `--bootstrap-resamples 10000 --bootstrap-seed 0` on this one call.
  - Every other registered mid-century run keeps its registered 2,000 resamples.
- **Primary condition:** the interval's upper bound is below 0, so A is better than R8b.
- **Reported alongside, not decided on:**
  - **Secondary:** pass 1 on the full set, with exposure stated.
  - **Reference check:** the blind pass 2, on both the zero-exposure subset and the full set. If the sign of A − R8b differs between pass 1 and pass 2, the ranking is reported as unresolved.
  - **Reference error:** the set's measured reference error is cited, with REVIEW_BATCH_SPEC's caveat when it exceeds 0.3%.

## Guards

A must show **no loss** against R8b on any guard. Following the R9 registration, a loss is an interval of CER(A) − CER(R8b) lying entirely above 0. The profile is `line_fold_v1`, every line is charged, and the bootstrap uses 10,000 resamples and seed 0.

| Guard | Lines | Cluster | A − R8b already observed (r9_gate_v1.json) |
|---|---|---|---|
| OLB Reshumot dev `olbreshumotlines_v1_dev`, view "all" | 3,254 / 55 units | unit | −0.005 [−0.046, +0.021] |
| Kevar, book minus its `sel.list` lines | 4,600 | line | +0.004 [−0.011, +0.019] |
| Yedi'ot ha-Teva, book minus its `sel.list` lines | 4,600 | line | −0.018 [−0.049, +0.005] |
| Brainin IA | 6,257 | line | −0.007 [−0.019, +0.006] |
| Brainin NLI | 4,046 | line | −0.020 [−0.042, +0.004] |
| Silman | 3,046 | line | −0.034 [−0.054, −0.012] |

- **These guard figures are already known, and all of them pass.** They come from the R9 gate's decodes of the same two models, so re-running them is a deterministic re-check, not a fresh test. Effectively the decision rests on the primary.
- **The guards are kept** so that a model that wins mid-century by giving up a guard book can't pass, and so the rule states the whole bar in one place.
- **Deviation:** if heocr-eval's re-run of any guard gives a figure other than the one above, that is reported as a deviation before the decision is read.

## Reported, never used for the decision

- **Stock tessdata_best `heb`** is reported on every set, the primary included. It is decoded exactly as the trained models are. It is a reference reader, not an arm.
- **ws dev** (257 lines) is reported with its known loss. A − R8b = +0.243 [+0.130, +0.362] in `r9_gate_v1.json`, an interval entirely above 0, which is a loss by the guard definition. It is not a guard.
  - **The loss is already seen**, so making it a guard would decide the test before it runs.
  - **It is outside the vertical.** It holds Wikisource transcription lines of mixed origin, not the new-printed vertical of decision 0018 that this test is about.
  - **It is small:** 257 lines.
  - A release card for A would have to state the regression.
- **Also reported:**
  - the mid-century full set, with exposure stated (the secondary);
  - the excluding_pointed figure;
  - per-series and per-decade strata;
  - the other R-series report sets.

## Outcomes

- **A passes** if the primary condition holds and no guard shows a loss.
  - **What a pass licenses** (heocr-lead, 2026-11-14): A becomes the R8b successor, and a weights release may follow.
  - **What it does not license:** describing A as better than R8b beyond what the card shows, which is this set, with the guards and ws dev stated beside it.
  - A release needs:
    - the usual model card, with stock Tesseract on every set and the ws dev regression stated;
    - an Apache-2.0 LICENSE;
    - a NOTICE built from `train_a.list`'s own sources (next section).
  - **No Knesset attribution and no safeguard 4:** `train_a.list` holds no Knesset lines (heocr-lead, 2026-11-14).
  - **Datasets:** any release that also ships a dataset follows the standing rule. heocr-engine's release tooling must refuse committee material before any R9 dataset release.
- **A does not pass** otherwise. R8b stays the released model, and the result is reported as it stands.
- **No partial credit.** A narrow miss on the primary is not re-tested on another set or with another checkpoint under this registration.

**The NOTICE must be recomputed from the list, not copied.**
- **Per-record line counts change.** A drops 119 inherited lines that hit eval targets and 44 holdout hits, so every count is recomputed from `train_a.list`.
- **Every NLI record must be free-use** ("public domain, free use"). The licence rule of 2026-11-10 must be re-checked on the final list: no Google-digitized NLI-API scan, no NC, ND or unknown-licence input.
- **The model contains no images or text.** The training lines are not distributed with it.

## Not claimed

- **Silver and young data.** The mid-century references are reviewed silver transcriptions. A pass compares two readers on one batch of 1949–2005 pages, not on Hebrew print in general.
- **Exposure is lexical.** Zero exposure is judged by word 6-grams on the reviewed text, not by visual similarity of the scans. Both A and R8b trained on rendered Reshumot text.
- **The units are the batch's own source units.** If the set has few units, the interval is wide and a pass is unlikely. That is a property of this test, not a reason to change it.
